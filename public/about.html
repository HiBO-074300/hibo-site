ABOUT

这里是 HiBO 的个人展示站点，用来沉淀技术文章与日常记录。

文章以 Markdown 文件存放，放在项目的 content/ 目录里，网站启动时自动扫描该目录并按时间倒序展示——不需要维护任何索引文件，把 .md 丢进目录，刷新页面就有。

写文章

在 content/ 下新建 .md 文件，开头写一段 front-matter 指定元信息：

---
title: 文章标题
date: 2026-10-09
category: 技术文章
summary: 一句话摘要，会显示在列表页。
---

正文从这里开始，支持 Markdown 常用语法。

文件名建议只用小写字母、数字和连字符（如 2026-10-09-hello.md），中文标题写在 front-matter 的 title 里。这样能避开中文文件名在 URL 里被拦截的老问题。

date 可以省略，省略时按文件修改时间排序。

资料放哪

散装的 PDF、HTML、Markdown 不必转成文章，直接在 config.json 的 sites 里登记目录，文件库会按目录浏览，首页也会把它们按修改时间排进「最近更新」。

技术栈

  • Node.js 原生 http 模块，零第三方依赖
  • 自带轻量 Markdown 解析器（lib/markdown.js）
  • 静态页面 + 若干只读接口（文章、文件库、工具、站点信息），不写数据库
  • 明暗主题与左侧栏时钟、日历都是纯前端，配置来自 config.json
